# FORKING

First of all, if you wanna fork this project for using it within your own bot, give the credits to this repository.

After the fork, scroll to the end of the code and change "YOUR TOKEN HERE" to your actual discord bot token, you can get it on Discord Developer Portal in the Bot panel.
Tokens can only be seen for ONLY one time because they're the main door the code use to access your bot so copy it and store in a safe place and NEVER SHARE YOUR TOKEN PUBLICLY

Then you'll need a cookie.txt in the same directory as the bot main archive if you gonna host it. Install Get Cookies.txt LOCALLY extension (https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc?hl=pt-BR&utm_source=ext_sidebar) 
on your browser and create an alt
yt account so you'll not be in risk of your main being taken down, then use the extension when logged in alt and copy or download your cookies.txt archive (it should
be saved with this exact name) and put it in the same directory/folder your code is located

CONGRATULATIONS! You now have a full working fork of my music bot, you can host it locally in your computer or take a hosting service of your choice
